### 🕹️ 소개
&nbsp;&nbsp;&nbsp;• Prject NT는 VR 멀티 리듬게임입니다.<br>
&nbsp;&nbsp;&nbsp;프로젝트 참여 인원은 총 9명이며, 개발자 5인, 기획자 4인으로 구성되어 있습니다.<br>
&nbsp;&nbsp;&nbsp;유니티로 인게임에서 플레이할 수 있는 리듬게임 곡을 만드는 에디터와 VR에서 플레이 가능한 프로그램을 제작했습니다.<br>
&nbsp;&nbsp;&nbsp;개발 기간은 약 2개월 소요되었으며, 기업과 협약을 맺어 가이드라인에 따라 프로그램을 공급하였습니다.<br>
